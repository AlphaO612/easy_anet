# Сборка серверного образа

Запускайте из корня репозитория ANet на Linux с Docker Buildx. Базовый сервер собирается без eBPF-шейпера. В конфиге используйте `[shaper]` с `enabled = false`. Обычная сборка Cargo по умолчанию включает шейпер.

Dockerfile закрепляет индексы Rust и Chainguard по digest. Для другого реестра передайте пару аргументов `RUNTIME_IMAGE` и `RUNTIME_DIGEST`, соответствующую опубликованному там образу.

```sh
docker buildx build --load -t anet-server:local -f contrib/docker/Dockerfile.server .
docker run --rm --read-only anet-server:local --help
```

Образ читает конфиг из `/etc/anet/server.toml`. Смонтируйте его только для чтения и обеспечьте доступ для UID/GID 65532. Ключи и сертификаты монтируются по путям из конфига. Проверка `--help` выполняется также при сборке и выявляет ошибки загрузки динамических библиотек. Пакеты сборочной стадии берутся из APT, их версии пока не закреплены снимком репозитория.

Для сетевой приёмки выделите серверу собственное сетевое пространство. Проверьте rootless-контекст Docker, доступ к TUN и минимальные права на его настройку. Healthcheck обнаруживает интерфейс TUN в пространстве контейнера. Приёмка туннеля требует подключения отдельного клиента и передачи TCP и UDP в обе стороны. Проверьте маршрут ответа, внешний адрес и повторное подключение после перезапуска. Повторите сборку и приёмку на amd64.
