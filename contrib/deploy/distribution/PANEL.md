# От приглашения до подключения

## 1. Дайте новой VPS адрес панели

Вход в админку через SSH-туннель использует адрес 127.0.0.1 на вашем компьютере. Новой VPS нужен собственный путь к API. Подготовьте отдельное имя, например `nodes.example.org`, направьте его записи A/AAAA на **VPS с панелью** и откройте на ней TCP 80 и 443. Если уже есть публичный HTTPS-прокси к API, используйте его адрес.

На VPS с панелью запустите:

```bash
f=$(mktemp) &&
curl -fL --retry 2 -o "$f" https://github.com/AlphaO612/easy_anet/releases/latest/download/setup-node-api.py &&
sudo /usr/bin/python3 -I "$f"
```

Введите DNS-имя, локальный порт панели (обычно 8088) и ваш email. Помощник настроит nginx и сертификат Let's Encrypt для этого имени, проверит HTTPS и напечатает адрес вида `https://nodes.example.org/api/v1`. Админку по-прежнему открывайте через свой SSH-туннель.

## 2. Зарегистрируйте выходной сервер

В **Серверы → Добавить сервер** укажите публичный адрес новой VPS, её SSH-логин и SSH-порт. UDP-порт ANet понадобится для VPN-трафика. Откройте его в панели провайдера. Если запись сервера уже создана, откройте её и выпустите свежее приглашение. У приглашения срок 15 минут и одно использование.

| Выбор в приглашении | Кто выполняет и где |
| --- | --- |
| **Автоматически по SSH** | Администратор в браузере вводит адрес HTTPS API, сверяет отпечаток SSH с консолью провайдера и вводит SSH-пароль новой VPS. Панель подключается к новой VPS, передаёт приглашение и запускает установщик. Подойдёт root либо пользователь с sudo. |
| **Самостоятельно** | Администратор новой VPS выполняет первую команду на своём компьютере для входа по SSH. Вторую выполняет уже в терминале новой VPS. Когда появится запрос кода, вставляет **код приглашения** из панели. Копируйте всю строку целиком. |

Код Base64 содержит одноразовый секрет. Передавайте его администратору этой VPS приватно. Выдавать код пользователю VPN не требуется. Завершение регистрации проверьте по статусу узла **Онлайн**. Добавление выхода и назначение клиентского маршрута — отдельные действия.

## 3. Создайте конфиги пользователя

1. Откройте **Профили и маршруты → VLESS для пользователя**.
2. Введите имя, например `Анна`, и нажмите **Создать получателя**.
3. Выберите маршрут, назовите устройство `Телефон` и нажмите **Создать конфиг**. Повторите с именем `Ноутбук` для второго устройства.
4. **Копировать VLESS** даёт один конфиг для импорта в клиент. **Получить ссылку** даёт подписку со всеми действующими конфигами этого получателя.
5. В поле публичного адреса подписок укажите HTTPS-сайт, на котором доступен путь подписки, например `https://nodes.example.org` (без `/api/v1`). Ссылку, которую сгенерирует панель, отправьте пользователю приватно. В клиенте он выбирает добавление подписки по URL и нажимает **Обновить**.

При замене или отзыве ссылки прежняя подписка перестаёт обновляться. Уже импортированные конфиги на устройствах сохраняют VPN-доступ. Мастер резервирует до 128 отдельных UUID на каждый маршрут VLESS. Если список маршрутов пуст, примените текущий полный выпуск к сохранённой сети с VLESS-входом. Команда и варианты продолжения указаны в [README](../../../README.md#уже-есть-панель).
