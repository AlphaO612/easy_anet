# Топология профилей через Ansible

Для первой публикации скопируйте [пример inventory](topology.example.yml) и задайте свои узлы и пути. На новой панели базовая ревизия равна 0. Для существующей конфигурации откройте «Топология профилей» → «Экспорт inventory». Скачанный YAML содержит опубликованные пути, политики и номер базовой ревизии. Список хостов для установки VPN остаётся в [inventory установки](inventory.example.yml).

Запустите на управляющей машине из корня checkout. Укажите адрес API той же панели и путь к локальному файлу с действующим административным токеном. API принимает HTTPS или HTTP на loopback. Для приватного файла токена используйте режим 0600.

```sh
export ANET_INVENTORY=profile-topology-4.yml
export ANET_API=https://panel.example.org/api/v1
export ANET_TOKEN_FILE="$HOME/.config/anet/admin-token"
compare_topology() {
    ansible-playbook -i "$ANET_INVENTORY" contrib/deploy/ansible/topology.yaml \
        -e "anet_topology_api=$ANET_API" \
        -e "anet_topology_token_file=$ANET_TOKEN_FILE" "$@"
}
compare_topology
```

В поле `diff` строки с минусом относятся к панели, с плюсом — к inventory. `diff: []` означает одинаковую конфигурацию. Ключи объектов сравниваются без учёта порядка, порядок правил и путей сохраняется. При редактировании сохраняйте многострочный блок `!unsafe |`, чтобы Ansible передавал содержимое как данные.

Для публикации запустите `compare_topology -e anet_topology_action=apply`. При совпадении базовой ревизии и содержимого текущий номер сохраняется. Изменение публикуется с проверкой базы в API. При конфликте экспортируйте текущий inventory, перенесите свои изменения и повторите сравнение. После успешной публикации экспортируйте новую ревизию. Для отката перенесите желаемый манифест из сохранённого inventory в свежий экспорт и опубликуйте новой ревизией. Флаг Ansible `--check` включает сравнение даже при выбранном `apply`.

Обычный `site.yaml` устанавливает узлы. Он не публикует топологию. Повторный запуск `topology.yaml` без параметра действия показывает расхождения и сохраняет сделанный в WebUI выбор.
